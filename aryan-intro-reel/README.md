# AryanIntro Remotion Reel

A standalone Remotion project for the silent, comic-style `AryanIntro` composition.

- 1280x720
- 30fps
- 1140 frames / 38 seconds
- Whiteboard-style hand-coded SVG animation

## Run Studio

```console
npm install
npm run dev
```

Open the Studio URL and select `AryanIntro`.

## Render MP4

```console
npm run render
```

The MP4 is written to `out/AryanIntro.mp4`.

## Render A Still

```console
npm run still
```

The checked midpoint scene stills are in `out/stills/`.
