# Boring Mode game documentation

`/boring` is an original, peaceful, open-world portfolio game set in a compressed version of
central Bhopal. These documents are the implementation contract for the vertical slice.

- [Chinatown Wars-inspired visual and gameplay reference](./chinatown-wars-reference.md)
- [Peaceful interaction language and three-mission design bible](./game-design-bible.md)
- [Offline Bhopal map data pipeline](./map-data.md)

The game borrows a design grammar—an angled overhead camera, compact objectives, cel-shaded
geometry, comic panels, and a PDA/GPS flow. It does not contain Rockstar assets, code, branding,
fonts, audio, dialogue, maps, mission text, or extracted game data.
